# ImgZip 0.3.6：复制未被压缩的其他文件

## 功能

界面在“包含子文件夹”前新增“复制其他文件”。仅在来源是单个文件夹时可用；单张图片或同目录多图任务不会复制父目录中的其他文件。

勾选后：

- 图片仍按预设压缩。
- 图片处理完成后复制普通非图片文件。
- 未勾选“包含子文件夹”时只复制来源文件夹当前层的其他文件。
- 勾选“包含子文件夹”时，其他文件按原目录层级复制。
- 包括隐藏/系统文件和 `Thumbs.db`，跳过符号链接、重解析点和空目录。

选项是全局偏好，切换后立即写入本机配置；每个已提交任务使用独立参数快照。

## 结果与失败

- 图片进度仍只统计图片。
- 任务卡片单独显示“其他文件 x / y · 已复制体积”。
- 摘要显示复制成功数；复制失败进入失败详情。
- 复制成功保留时间与可复制的基础文件属性。
- 任一项复制失败且已有成功项时任务为 `partial`；没有成功项时为 `failed`。
- 来源没有图片但有可复制文件时仍创建输出并完成归档。
- Dry run 只报告计划复制的文件数，不创建输出或复制文件。
- 复制阶段按文件响应取消；当前文件完成后停止后续复制，已发布文件保留。

## 实现

- PC worker 使用临时文件复制、恢复时间/属性后原子改名。
- NAS worker 使用 `cp -p` 加同目录硬链接原子发布。
- 名称冲突按大小写不敏感方式编号，不覆盖已有文件。
- 协议保持 v1，新增可选 `copyTotal/copyCompleted/copied/copyFailed/copiedBytes` 与 `copy` 事件。

## 验证

- 43 组 C# / PowerShell 检查通过。
- NAS worker 并发检查 4 组通过。
- NAS 复制检查覆盖当前层、递归、隐藏文件、`Thumbs.db`、符号链接跳过、mtime 保留、dry-run 和仅复制文件。
- PC 检查覆盖递归层级、复制进度、隐藏文件、复制失败 `partial`、时间保留和配置持久化。
- 已安装 0.3.6 并使用真实 caesiumclt 验证：1 张 JPEG 与 3 个其他文件全部成功归档，输出包含压缩图、`note.txt`、`Thumbs.db` 和递归子目录文件。
