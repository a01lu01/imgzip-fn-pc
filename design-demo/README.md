# ImgZip · Windows 11 设计演示

本目录是重写计划的第一阶段：用三版 HTML 确认布局。最终应用采用 WinUI 3 + C#；用户选定方案后再实施原生界面和双引擎接入。

## 打开

直接用 Mac 浏览器打开 [选型入口](index.html)，或分别打开：

| 方案 | 入口 | 默认应用窗口 | 侧重点 |
| --- | --- | --- | --- |
| A · 轻量工具窗 | [a.html](a.html) | 760 × 640 | 紧凑单页、快速操作 |
| B · Windows 设置风格 | [b.html](b.html) | 960 × 720 | 设置分组、留白、渐进展开 |
| C · 双栏工作台 | [c.html](c.html) | 1120 × 760 | 当前文件列表与参数并排 |

不需要 npm 或外部资源。小于默认窗口的浏览器会收窄布局；高级设置在窗口内滚动，底部任务区固定。

如浏览器限制 `file:` 页面历史导航或本地存储，可以在本目录启动本地 HTTP 服务：

```sh
rtk proxy python3 -m http.server 8765 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8765/`。此服务只提供静态文件，不处理上传或执行压缩。

## 演示方式

1. 在顶栏切换 A/B/C，同一页面内切换保留当前参数和模拟任务状态。
2. 在窗口外的“预览状态”选择空状态、待开始、压缩中、成功、部分失败、失败、已取消、引擎不可用。
3. “模拟结束”控制点击开始后约 10 秒到达的结果。默认成功；仅预演遇到预设部分失败时按失败展示。
4. 选择图片或一个文件夹，也可拖入多张图片或单个文件夹。重新选择会替换当前来源；只读取文件名、大小及目录层级，不读取图片内容。浏览器不提供本机完整路径，因此导入后的路径只是展示说明。
5. 子文件夹默认不纳入任务；勾选“包含子文件夹”会更新数量、大小和 C 版列表。文件类型展示并不保证实际 caesium 版本支持全部格式。
6. 点击预设，再展开高级设置：可更改格式、质量、缩放方式、尺寸、目标体积（字节）、线程、无损、不放大和仅预演。无损禁用质量与目标体积；不缩放禁用尺寸与不放大；只允许一种缩放方式。
7. 设置面板可填写示例 NAS 地址、端口、用户和私钥路径；“模拟测试连接”只校验表单并显示模拟成功，不运行 SSH。关闭面板后输入清空。
8. 结果中的压缩比例固定为模拟节省 42%，只针对成功项计算。预演不展示虚构的已生成输出。输出文件夹按钮打开路径说明，不访问系统目录。

界面按钮真实响应，但所有压缩、连接和文件处理结果均为演示。原型中的窗口最小化、最大化和关闭标记仅示意原生标题栏位置。

## 配色和主题

`styles.css` 保留用户指定的 `--window-bg`、`--card-bg`、`--text`、`--subtext`、`--hover`、`--selected`、`--border`、`--input-border`、`--shadow`、`--accent`、`--accent-text`、`--success`、`--warning`、`--error`、`--danger`、`--info`，浅色/深色值均按提供的色表设置。

- 主按钮、开关和进度指示使用 `--accent`，文字链接使用 `--accent-text`；滚动条与引擎选择使用 `--selected`。
- 默认 `theme: "system"`，监听 `prefers-color-scheme`；手动选择经根元素 `data-theme="light|dark"` 生效。
- 浏览器配置键为 `imgzip-demo-config`，值仅为 `{"theme":"system|light|dark"}`。不保存来源、文件元数据或 NAS 字段。
- 刷新后恢复主题；配置损坏或存储不可用时退回系统主题，仍可在当前页面手动切换。`file:` 下存储行为因浏览器而异，通过本地 HTTP 打开可以共享三版配置。
- 卡片的淡紫、信息和状态底色由指定颜色混合生成；不另引入蓝色强调主题。字体优先使用 Windows Segoe UI，Mac 回退系统字体和苹方。

## 非视觉检查

在仓库根目录运行：

```sh
rtk proxy node design-demo/verify.cjs
```

检查脚本语法、所有入口的本地资源引用、主题配置解析、预设切换、参数边界、递归范围、部分失败统计、输出路径，以及两套配色的精确值。此检查不启动浏览器，不验证视觉和交互。

## 请用户验收

- 对比 A/B/C 的信息密度、主要按钮位置、文件来源和参数的可读性。
- 切换浅色、深色、跟随系统，刷新后检查手动设置是否恢复。
- 展开高级参数和设置面板，检查滚动、键盘焦点、Esc 关闭，以及不同窗口宽度。
- 切换所有预览状态，尝试开始、取消、继续压缩、错误详情和输出说明。
- 选择一个带子目录的文件夹，检查递归开关与 C 版列表；检查中文、空格和特殊字符文件名。
- 选择 A/B/C，或明确指出要组合的区域，例如“B 的主布局 + C 的文件列表”。

本阶段不包含 WinUI 编译、真实 PC/NAS 压缩或 Windows 右键菜单验证；现有 PowerShell 文件保持原样。
